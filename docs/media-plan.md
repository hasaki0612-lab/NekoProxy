# README 实机素材规划

仅预留 4 个位置，目前不提供 GIF，也不把自动 RenderTargetBitmap 截图称为桌面录屏。

| 素材 | 建议时长 / 内容 | 公开前检查 |
| --- | --- | --- |
| 添加 VPS | 8–12 秒；空列表、填写、保存、选中 | 使用 RFC 文档 IP、虚构备注；认证输入不入镜 |
| 部署流程 | 10–15 秒；协议、摘要、进度与分层结果 | 隐藏 UUID、Short ID、密钥与域名；真实执行片段须有授权且不能把测试结果伪装成生产承诺 |
| 管理 / 监测 | 8–12 秒；节点选择、曲线悬浮、暂停和恢复 | 用授权且可公开的样本，或展示明确的离线空状态；不伪造实时数值，不改现有动画 |
| 配置导出 | 6–10 秒；选择客户端、导出成功、导入指引 | 不显示链接、二维码、文件内容、用户路径或剪贴板历史 |

建议 960–1200px 宽、10–15fps、每段约 2–5MB，避免自动循环大段安装过程。用原生 Windows 窗口录制，画面聚焦单个任务，不录聊天/任务栏隐私；浅深主题各选少量片段即可。

现有验收目录包含真实 VPS 地址、节点信息、文件路径，部分资料还有二维码/认证参数界面，因此不直接作为公开 README 素材。历史生成截图也不能冒充实机录屏。应重新录制，并逐帧检查；脱敏不能只遮挡第一帧。录屏选择器会遮挡聊天，所有操作说明应在进入框选前完成，或采用可独立操作的录屏工具。

文件名占位仅在 README 注释中，未加入断链图片、模拟 GIF、真实凭据或远程上传。
